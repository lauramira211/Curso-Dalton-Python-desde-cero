# Curso Dalton — Python desde cero

Apuntes y ejercicios del curso de Python (Dalto), respaldados desde mi computador.

## Contenido

- `Variables/Variables.py` — concatenación de textos (f-strings y `+`) y operadores de pertenencia (`in` / `not in`).
- `Tipos de datos/Datos-simples.py` — str, bool, int y float; comentarios con `"""` triples.
- `Tipos de datos/Datos-compuestos.py` — primeros apuntes sobre datos compuestos (listas).
